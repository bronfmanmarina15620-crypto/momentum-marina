# מומנטום — מערכת הפעלה אישית

אפליקציית PWA אישית בעברית (RTL) לניהול **8 הרגלים** לבניית חיים של מומנטום.

**כתובת חיה:** https://bronfmanmarina15620-crypto.github.io/momentum-marina/

## מה בפנים

| מסך | תוכן |
|------|------|
| **היום** | כל 8 ההרגלים עם צ׳ק־ליסטים ושדות (Brain Dump, עדיפויות, תודות, JIT, מדדים…) |
| **התקדמות** | מפת חום 12 שבועות, סטטיסטיקות ורצפים — **נשמרים גם אחרי ימים חסרים** |
| **ההרגלים** | מדריך ל־8 ההרגלים + פירמידה, Eustress/Distress, ארכיטקטורת 1% |
| **סקירה** | סקירה שבועית (ראשון–שבת) + פונקציית אילוץ |
| **הגדרות** | כוכב צפון, אתגר, מסנני סביבה, ייצוא/ייבוא JSON |

### 8 ההרגלים
1. מנצחים את המחר בלילה  
2. הגנת 60 דקות ראשונות  
3. משפך 1-2-3  
4. Just-in-Time learning  
5. עיצוב סביבה  
6. מדדים  
7. מומנטום  
8. בחירה בקושי  

## איך לפתוח

1. היכנסי ל־https://bronfmanmarina15620-crypto.github.io/momentum-marina/
2. או פתחי מקומית את `index.html` אחרי `git clone`

אין חשבון, אין שרת נתונים — הכול נשמר ב־**localStorage** במכשיר, עם גבולות יום לפי **Asia/Jerusalem**.

## התקנה למסך הבית (PWA)

- **iPhone / Safari:** כפתור שתף ← «הוסף למסך הבית»
- **Android / Chrome:** תפריט ⋮ ← «התקן אפליקציה» או «הוסף למסך הבית»

אחרי ההתקנה האפליקציה נפתחת במסך מלא ועובדת גם אופליין (service worker).

## גיבוי

במסך **הגדרות** → ייצוא JSON. מומלץ לשמור את הקובץ ב־Drive / במייל מדי פעם. ייבוא מחזיר את כל ההיסטוריה.

## פיתוח מקומי

```bash
git clone https://github.com/bronfmanmarina15620-crypto/momentum-marina.git
cd momentum-marina
# אפשר לשרת סטטי פשוט:
python3 -m http.server 8080
# ואז לפתוח http://localhost:8080/
```

ל־GitHub Pages הנתיב הבסיסי הוא `/momentum-marina/`.
